# 傳教100週年紀念衫｜各地統計與意向登記

正式網址：https://www.philemon.com.tw/shirt/

## 公開網站

- 左側**只呈現「各地統計」地圖**，不展示逐教會名單表格；地圖標記可顯示該教會的累計件數。
- 頂端保留「目前有 X 人訂購 X 件」，這裡的人數是不同有效回覆代碼數，不等於已驗證的真實人數或正式購買。
- 日期至 **2026/12/10 23:59**（臺灣時間），超過100件意向可評估再製作。
- 表單：教會、**完整姓名**（繁／簡中文或英文）、**本人填寫／書報組代填**、11種尺寸件數、同意勾選。
- 書報組每次代填一位登記人；成功後清空姓名與尺寸件數，保留教會與填寫身分，繼續下一位。不會覆蓋上一人的資料。
- 表單說明：「調查結束並彙整意向後，書房會將姓名、尺寸與件數依所屬教會提供書報組核對。紀念衫到貨時，再請書報組辦理正式下單。」本人與代填者均需勾選同意；代填者須先取得本人同意。
- **公開 JSONP API 不輸出姓名、尺寸明細或回覆代碼，只輸出總件數、登記人次、各教會 ID 的件數彙總與更新時間。**

## 私人後台

Google 管理試算表：
https://docs.google.com/spreadsheets/d/1YeD69Wnvbwvf76ouee0qbKuwsMgRM491HlErmONOUXc/edit

- **意向回覆**：A:L 的完整資料，K為教會中文名稱、D為姓名、L為可閱讀的尺寸明細、I為填寫方式、J為提供名單同意。G「排除」不計入公開統計。
- **書報組名單**：依教會彙整**已同意**且未排除的姓名、尺寸、件數、填寫方式、更新時間；可用 Google Sheets 欄位篩選各教會名單。試算表保持私人，**不要把整份試算表分享給各教會**；逐一篩選各自資料後再傳送。
- 舊版只有姓氏的回覆仍保留在「意向回覆」，J欄為「待補同意」，**不會出現在可交給書報組的名單**；必須先補完整姓名並取得本人同意。

## 需要由 Apps Script 擁有者更新（必要）

GitHub 前端與私人試算表已更新，**實際 Google /exec 仍須由本人發布新版本**，否則新版姓名與代填同意欄位無法正式收件。

1. 在已存在的 Apps Script 專案「百週年紀念衫意向調查」，完整貼上 [最新 Code.gs](https://github.com/philemon86/philemon202603-news/blob/master/shirt/apps-script/Code.gs) 的 Raw 內容，儲存。
2. 「部署 → 管理部署作業 → 原網頁應用程式 → 編輯（鉛筆）→ 建立新版本 → 部署」。
3. 原本 /exec 網址不需更換。重新開啟網站，填一筆測試姓名、教會、尺寸、件數，勾選同意。
4. 確認「意向回覆」新增 A:L 的資料，且「書報組名單」顯示該教會及姓名。測試資料在原表 G 欄改「排除」後，公開統計不計入。

**安全措施**：新 Google Bridge 使用 `named-consent-v1` 版本識別。若仍連到舊版後端，前端會停用送出並提示先更新，不會以舊版姓氏表單違反使用者的知情同意需求。

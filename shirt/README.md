## Google Apps Script 部署紀錄與維護方式

GitHub Pages 本身不能接受持久的意向資料。請使用本對話提供的 **更新版單檔 Code.gs** 部署 Google Apps Script 網頁應用程式：

1. 用 `zalmunna17@gmail.com` 開啟 <https://script.new/>，貼入更新版 Code.gs（無須另建 Form.html）。
2. 執行 `setupOnce()`，完成 Google 授權。
3. 「部署 → 新增部署 → 網頁應用程式」，以本人身分執行，允許所有人存取。
4. 將部署後 `/exec` 網址填入 `shirt/config.js` 的 `scriptUrl`。

**`shirt/config.js` 已填入正式 `/exec` URL，仍須驗證真實表單送出。**
請勿把整份 Google 試算表開放成「知道連結的人可檢視」；公開範圍僅限 Apps Script 對外輸出的統計摘要。

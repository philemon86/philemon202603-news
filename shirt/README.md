# 傳教100週年紀念衫｜各地統計與意向登記

正式網址：https://www.philemon.com.tw/shirt/

## 公開網站

- 左側直接呈現「各地統計」地圖，不展示逐教會名單；地圖可顯示各教會累計件數。
- 頂端顯示「目前有 X 人訂購 X 件」，X 人取有效登記筆數、X 件取有效衣服件數。舊 Google 公開 API 沒有回傳人數時，總數為1件即可確定是1筆登記，前端先顯示 **1人訂購1件**；其他數量不猜測人數，待新 Google API 發布後顯示正確筆數。
- 2026/12/20 23:59（臺灣時間）截止，預計滿100件就會製作（預計農曆年後到貨）。
- 表單僅需選擇教會、填寫「姓名」（提示：**輸入書報組或全名即可**）、11種尺寸與件數，。沒有「本人填寫」或「書報組代填」切換。
- 一筆登記一個名稱及件數，成功後清空姓名和尺寸，保留教會，方便連續登記。
- 調查結束後，書房依所屬教會彙整意向與尺寸件數供書報組核對；紀念衫到貨時請書報組正式下單。本次不用付款，不代表正式訂購。
- 公開 Google API 只回傳總人次、總件數、每教會 ID 的彙總件數與時間，不輸出姓名、回覆代碼或個人尺寸明細。

## 私人後台

[Google 管理試算表](https://docs.google.com/spreadsheets/d/1YeD69Wnvbwvf76ouee0qbKuwsMgRM491HlErmONOUXc/edit)

- 「意向回覆」保留 A:L 原始登記資料，D為填寫名稱、I為內部備註、J為提供名單同意、K為教會、L為尺寸件數。
- 「書報組名單」僅彙整已同意且未排除的「教會、姓名／書報組、尺寸、件數、更新時間」；可先依教會篩選再分送個別書報組，不要公開或傳送整份原始試算表。
- 舊版只有姓氏的資料仍在原始記錄，尚未取得提供名單的同意，不列入可交給書報組的名單。

## 啟用新版本 Apps Script

**GitHub 網站與私人試算表已更新，但使用者仍需更新原有 Google Apps Script 部署。** 新的前後端通訊使用 `named-notice-v3`，避免舊後端強制要求已取消的「填寫方式」。

1. 在 [最新 Code.gs](https://github.com/philemon86/philemon202603-news/blob/master/shirt/apps-script/Code.gs) 點 Raw 複製全部，取代原 Apps Script 專案的程式碼並儲存。
2. 部署 → 管理部署作業 → 原網頁應用程式 → 鉛筆編輯 → 建立新版本 → 部署。原 `/exec` 不變。
3. 測試一筆真實姓名或「書報組」登記，確認原始試算表新增一筆，公開頁面人次和件數同步更新；如果是測試資料，事後在 G 欄標「排除」。

# Homepage Editing Notes

`index.html` must be edited as UTF-8.

Rules for future edits:

1. Only make minimal targeted edits to links/cards/buttons that need updating.
2. Do not rewrite the whole file through tools/workflows that may re-encode Traditional Chinese text.
3. Before editing, verify the file renders correct Chinese with a UTF-8 read.
4. After editing, verify these strings still display correctly:
   - `腓利門電子報`
   - `腓利門出版品`
   - `最新一期電子報`
   - `Latest Issues`
5. When syncing from a known-good copy, prefer raw file copy over text transcoding.
6. If a clean deploy clone exists, use it as the source of truth for homepage publishing.

Recommended workflow:

1. Read with UTF-8.
2. Patch only the needed lines.
3. Re-read with UTF-8.
4. Confirm homepage Chinese text is still intact.
5. Then deploy.

## Monthly newsletter archive

The `LATEST_NEWSLETTER` and `NEWSLETTER_INDEX` comment blocks are generated by
`scripts/build_newsletter_index.py`. Do not edit their individual rows by hand.
The Pages deployment runs this generator before uploading the site.

- Publish a month in `YYYY-MM/index.html`; valid months are discovered automatically.
- Add `zh-cn.html` and/or `en.html` in that folder to expose those language links.
- Newest months appear first, grouped by year; the homepage latest issue follows them.
- The featured title and summary come from the latest issue's HTML metadata.
  An optional `newsletter-title` meta tag overrides the shortened page title.
- A draft folder without `index.html` is not listed. A published future month
  becomes the latest; there is no date embargo.
- Generated links are static HTML and work without JavaScript or GitHub API access.

Before publishing, run `python scripts/build_newsletter_index.py` and
`python -m unittest discover -s scripts -p test_newsletter_index.py`.
